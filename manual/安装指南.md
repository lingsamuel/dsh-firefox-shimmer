# 安装指南

在运行 DeepSeek Harness 的机器上下载插件的 `.tgz` 安装包，执行以下命令。将路径替换为下载位置。

```sh
dsh plugin --profile web add /path/to/dsh-firefox-shimmer-0.1.0.tgz
```

启动或重启 DSH Web 服务，然后打开 Firefox 中的 DSH 页面。运行一次包含工具调用的会话，检查计时行和工具状态的扫光。

卸载时执行以下命令，然后重启 DSH Web 服务并刷新页面。

```sh
dsh plugin --profile web remove dsh-firefox-shimmer
```
